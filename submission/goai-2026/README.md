# GOAI 2026 submission package

**Track:** Boundless Agents  
**Topic:** AI + Education

## Final submission files

- `village-of-shadows-project-brief.md` — Round 1 project brief, under 500 words.
- `village-of-shadows-goai-proposal-deck.pdf` — final 13-page proposal deck and preferred upload format.
- `village-of-shadows-goai-proposal-deck.pptx` — editable source deck.
- `village-of-shadows-goai-deck-preview.png` — contact-sheet preview.

The learning story is explicit in both artifacts: the learner configures and predicts, participates inside the graph, observes the system in God Mode, receives an evidence-backed Learning Debrief, and can replay with a controlled model or personality change.

The debrief is implemented in the product. It reconstructs human interrupts, public/private information boundaries, MCP tool outcomes, per-seat memory growth, and comparable model decisions from durable game evidence, then maps them to agentic-AI concepts and suggests the next experiment.

Supporting artwork in this directory is used by the deck and may also be reused in the hackathon portal listing.
